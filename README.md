# 银发合作报告

幕景宇宙（杭州，AIGC 文化艺术团队）写给养老机构与社区合作方的一份报告。单页长文，带目录、真实案例配图与出处链接。

打开 [`index.html`](index.html) 就是整份报告。

## 这份报告讲什么

- 老人现在卡在哪：公告栏、服务窗口、日历、手机课四件事，配四张真实资料图
- 我们做出过什么：六个作品的实际页面与短片
- 一个老人的下午：真实案例（新加坡 Lily 居家智能体、西溪智慧养老、日本 6 栋 301 房等）配报道原图，虚构的「陈阿姨」五段配 AI 示意图
- 日本与新加坡怎么做：政策原文与统计口径
- 软件与游戏：能查到的研究，写了样本量、效应量、置信区间与证据质量
- 三种合作方式、先试一次怎么试
- 出处：所有引用可点

## 这个仓库里有什么

```
index.html          报告本体，单文件，样式与脚本都在里面
assets/pains/       第一节的四张资料图
assets/works/       作品章节的封面图与短片
assets/cases/       真实案例的报道原图与 Lily 短片
assets/illus/       「陈阿姨」五段用的 AI 示意图
assets/fonts/       阿里巴巴普惠体 3.0 的子集字体（站内用字）
```

## 几条写死的边界

- 没有在养老场景做过试点，所以全篇不写效果数字与百分比
- 不做医疗判断、不做健康监测宣称
- 没上线的设计明确标「设计提案」「示意图」，不写成已有产品
- AI 示意图不含任何文字，不对应真实个人与机构
- 案例图片与引文只作说明，版权归原作者；引用注明出处

## 本地打开

```bash
git clone https://github.com/LiliLIN0324/silver-report.git
cd silver-report
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/index.html
```

直接用 `file://` 打开也能看，字体与视频走相对路径，没有外部依赖。

## 技术栈与依赖

| 层 | 用什么 | 为什么 |
| --- | --- | --- |
| 页面 | 单文件 HTML + 原生 CSS/JS | 发给合作方不用装东西，双击就能看，微信里也能打开 |
| 排版 | CSS 变量 + 一个 860px 断点 + `@media print` | 桌面、手机、打印三套只靠一处样式维护 |
| 卡片 | 浅米底 `--soft` + 4px 圆角，无边框无阴影无序号 | 版面靠字号与留白分层，不靠装饰 |
| 字体 | 阿里巴巴普惠体 3.0，`fonttools` 按站内用字切子集，woff2 | 中文全字体几 MB，子集后两个文件各 123KB |
| 图片 | jpg（1800px 宽、q82）+ `loading="lazy"` | 首屏只加载看得见的部分 |
| 灯箱 | 原生 JS 监听缩略图，Esc 关闭 | 案例原图能点开看细节，不引第三方库 |
| 视频 | `<video>` + `preload="none"` | 不自动下载，点开才取流 |
